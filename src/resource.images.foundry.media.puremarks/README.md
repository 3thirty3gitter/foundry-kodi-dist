# Foundry Media - Pure Marks

105 mapped format-icon paths:31 sourced marks and74 original technical diagrams/labels. The original technical glyphs are not official brand logos. See PROVENANCE.md and the per-asset manifest for attribution, copyright classifications and trademark limitations.

Install/update Foundry or Slate, then open Skin settings > Artwork > Media icon pack and choose Pure Marks. Selection is saved separately for each skin. Built-in icons remain the default; installing the pack does not change your selection. The resource can also be installed independently from the Foundry repository.

Icons use transparent backgrounds designed for the skins' dark media surfaces. White marks are not suited to white backgrounds. Optional audio variants remove only fully transparent margins; all remaining RGBA pixels are unchanged. The wider audio presentation preserves surrounding controls; Live title text retains its existing scrolling behavior in a slightly narrower viewport. Very small secondary taglines may remain unreadable at television distance.

Missing, disabled, invalid or unmatched artwork falls back to existing skin icons. No downloads, account linking, network tracking or automatic add-on enabling are performed by the selector.
