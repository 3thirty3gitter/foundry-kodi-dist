# Pure Marks: provenance and restrictions

## Scope and release gate
This user-approved artwork pack contains 31 sourced format-mark asset paths plus 74 original technical glyph paths (105 populated base paths). It is not a complete official-logo collection. Original technical diagrams and factual format labels are included and explicitly identified in the manifest; they are not official logos. Low-resolution Lucent/Bingie sample artwork is excluded. No generic fallback image is included. Runtime must use existing skin artwork for each absent specific path.

The authoritative per-output source URL, source hash where recorded, rendered-file hash, license statement and release status are in resources/media-pack.json. Editable SVGs for the 74 original technical glyph paths are included in original-vectors. Sourced-mark vectors and captured research evidence remain in the development archive; unused research artwork is not distributed with this pack. The sourced mark count is a deployed path count including aliases, not a count of unique sources.

## Rendering and semantic constraints
Deployed icons are 384 x 192 transparent PNGs rendered from vector originals, not raster upscales. Shape-preserving white rendering is used for dark-background readability. AV1 and Vorbis preserve meaningful internal colours; AV1 lettering is made white for contrast. FLAC's explicit black background path was removed, retaining the foreground artwork. Rendering, scaling, colour treatment, background removal and transparent-canvas positioning are modifications, not newly official brand variants. Review brand usage restrictions before release.

Aliases preserve format identity: DivX is shared by divx/div3/dx50; Vorbis is not applied to all Ogg; AAC is not applied to audio AVC; HEVC is not represented by an x265 encoder mark. Atmos aliases require actual supported codec metadata, not merely channel count. DigitalEurope device-certification UHD and Sony-specific Full HD research marks were not substituted for generic video resolutions.

## Validation and release status
All 105 base PNG paths have verified recorded hashes, dimensions and nonempty alpha bounds. Artwork style was approved by the user. Runtime/native validation and publication remain separately recorded by the release owner; artwork approval alone does not claim deployment. resources/media-pack.json is authoritative for release status. Optional OSD audio derivatives are explicit alpha-bound crops: source hash, exact bbox and output hash are recorded in osd_derivatives, and runtime verifies exact RGBA crop identity. Base artwork is retained unchanged.

## VP8/VP9 exclusion decision (2026-11-15)
The official press page identifies authorized artwork but supplies no explicit redistribution or modified-colour license. The official licenses page concerns codec software, specifications and bitstreams, not the artwork. To avoid assuming a license, Official VP8/VP9 logo artwork and unrelated research artwork are omitted from this release. Both paths use original video pictograms and factual labels, not the restricted official artwork. Primary sources checked: https://www.webmproject.org/about/press/ and https://www.webmproject.org/license/ . This resolves the artwork inclusion ambiguity without asking the user to make a legal judgment. It does not declare other trademarks unrestricted or skip release-owner QA.

## Original technical artwork
74 original diagrams and factual labels are provided under CC0-1.0. Editable SVGs are included in original-vectors. Screen shapes represent aspect and display concepts, waveforms represent audio, channel diagrams show counts without claiming speaker layout. No official VP8/VP9/Xvid logo is included. Xvid is represented by an unstylized factual label. See REVIEW-NOTES.md. All 105 base paths are populated. Original technical glyphs and sourced trademarks remain distinguished; do not describe this as 105 official brand logos.
