Usage policy: https://eccc-msc.github.io/open-data/usage-policy/readme_en/

The service asks applications at 86,400 requests/day or more to contact it for a suitable access plan. A broad rollout needs an application-wide usage plan; per-device caching alone does not guarantee staying below this threshold. No contact, subscription or agreement has been made by this prototype.

Government weather artwork is not copied or redistributed. Condition codes map to Kodi's bundled default weather-icon resource. The two Foundry card/line textures are original generated UI primitives. Government icon conditions: https://eccc-msc.github.io/open-data/msc-data/citypage-weather/readme_citypageweather-datamart_en/

API documentation: https://eccc-msc.github.io/open-data/msc-data/citypage-weather/readme_citypageweather_en/

No full CAP, AQHI or radar collection is implemented. Advisory metadata is not a complete emergency bulletin service.
