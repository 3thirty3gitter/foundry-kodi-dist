# Pure Marks authentic-only candidate: provenance and restrictions

## Scope and release gate
This is an experimental, NOT RELEASE APPROVED candidate containing 31 sourced format-mark asset paths and 74 intentionally absent unresolved paths. It is not a complete official-logo collection. No provisional neutral pictograms, standalone descriptor constructions, or low-resolution Lucent/Bingie sample artwork are included. No generic fallback image is included. Runtime must use existing skin artwork for each absent specific path.

The authoritative per-output source URL, source hash where recorded, rendered-file hash, license statement and release status are in resources/media-pack.json. Source vectors and captured evidence remain in the separate original development candidate; this reduced candidate deliberately omits the evidence directory, which includes unused research artwork.

## Rendering and semantic constraints
Deployed icons are 384 x 192 transparent PNGs rendered from vector originals, not raster upscales. Shape-preserving white rendering is used for dark-background readability. AV1 and Vorbis preserve meaningful internal colours; AV1 lettering is made white for contrast. FLAC's explicit black background path was removed, retaining the foreground artwork. Rendering, scaling, colour treatment, background removal and transparent-canvas positioning are modifications, not newly official brand variants. Review brand usage restrictions before release.

Aliases preserve format identity: DivX is shared by divx/div3/dx50; Vorbis is not applied to all Ogg; AAC is not applied to audio AVC; HEVC is not represented by an x265 encoder mark. Atmos aliases require actual supported codec metadata, not merely channel count. DigitalEurope device-certification UHD and Sony-specific Full HD research marks were not substituted for generic video resolutions.

## QA and remaining work
Output hashes and dimensions are recorded in resources/media-pack.json. Windows staging rechecked all 31 mapped PNG hashes without mismatch. Artwork review at badge proportions is complete, but source/rights review, full format coverage, both-skin runtime testing, missing-asset fallback tests and release approval remain separate gates. No asset has release_approved=true; release_status remains experimental-review-required. No publication is authorized by this documentation correction.

## VP8/VP9 exclusion decision (2026-11-15)
The official press page identifies authorized artwork but supplies no explicit redistribution or modified-colour license. The official licenses page concerns codec software, specifications and bitstreams, not the artwork. To avoid assuming a license, VP8/VP9 PNGs and all research/source artwork are omitted from this release subset. Both paths are explicitly unresolved and require the built-in fallback. Primary sources checked: https://www.webmproject.org/about/press/ and https://www.webmproject.org/license/ . This resolves the artwork inclusion ambiguity without asking the user to make a legal judgment. It does not declare other trademarks unrestricted or skip release-owner QA.
