# Optional SIMKL setup

Install **Foundry SIMKL Setup** from Foundry Repository > Program add-ons. It works independently of the active skin. It is not automatically installed by a skin or Build update.

Running the tool presents an explicit warning before requesting installation of the official SIMKL tracker. Installation can resume tracking and queued history on an already-linked profile. Cancel makes no changes. A previously disabled tracker stays disabled. For an enabled tracker, a separate confirmation opens its settings; Foundry never pairs an account, changes settings, imports history, or handles tokens.

The official service provides playback scrobbling/native-library synchronization according to its configuration. This does not add provider watchlist widgets, guarantee arbitrary provider identity, or grant access to the user's SIMKL account. Users link through the official PIN flow themselves.

Validation uses disposable profiles without credentials. No real account tracking, PIN pairing or Shield behavior is claimed.
